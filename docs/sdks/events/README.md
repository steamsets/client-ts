# Admin.Events

## Overview

### Available Operations

* [counts](#counts) - Count a product's staff events
* [list](#list) - List a product's staff events

## counts

A product's events per kind and severity in the last minute and the last hour, and since midnight UTC, for the counters of the admin Live page. SteamSets needs admin.access, Steam Levels levels.admin.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="admin.events.counts" method="post" path="/v1/admin.events.counts" -->
```typescript
import { SteamSets } from "@steamsets/client-ts";

const steamSets = new SteamSets({
  token: "<YOUR_BEARER_TOKEN_HERE>",
});

async function run() {
  const result = await steamSets.admin.events.counts({
    product: "steamsets",
  });

  console.log(result);
}

run();
```
