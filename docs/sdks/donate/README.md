# Donate

## Overview

### Available Operations

* [getGoal](#getgoal) - Get this month's donation goal progress
* [getPrepaid](#getprepaid) - Get your prepaid supporter balance
* [updatePrepaid](#updateprepaid) - Choose the tier your prepaid balance pays for

## getGoal

Public — no auth required. Aggregated per calendar month (UTC). Each supporter carries their own total for the month.
