# Admin.Roles

## Overview

### Available Operations

* [create](#create) - Create a role
* [delete](#delete) - Delete a role
* [list](#list) - List roles
* [listHolders](#listholders) - List role members
* [reorder](#reorder) - Reorder roles
* [setGrants](#setgrants) - Set a role's grants
* [setResources](#setresources) - Set a role's resources
* [setSettings](#setsettings) - Set a role's settings
* [update](#update) - Update a role
* [uploadIcon](#uploadicon) - Upload a role icon

## create

Creates a role that ranks above every existing role, with no members, grants or resources. Needs roles.manage.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="admin.roles.create" method="post" path="/v1/admin.roles.create" -->

```typescript
  token: "<YOUR_BEARER_TOKEN_HERE>",
});

  const result = await steamSets.admin.roles.create({
    description: "Friend of SteamSets",
    name: "Stasik",
  });

  console.log(result);

run();
```
