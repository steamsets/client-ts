# Badge

## Overview

Any request that is related to steam badges, mostly badge search/tagging related.

### Available Operations

* [plan](#plan) - Plan which Steam Market sets to craft to reach a level

## plan

Logged in, the plan uses your badges, XP and optionally your cards. Without a session it is an estimate from fromLevel with no badges crafted, limited per IP.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="badge.plan" method="post" path="/v1/badge.plan" -->
```typescript
import { SteamSets } from "@steamsets/client-ts";

const steamSets = new SteamSets({
  token: "<YOUR_BEARER_TOKEN_HERE>",
});

async function run() {
  const result = await steamSets.badge.plan({
    targetLevel: 314222,
  });

  console.log(result);
}

run();
```

### Standalone function

The standalone function version of this method:

```typescript
import { SteamSetsCore } from "@steamsets/client-ts/core.js";
import { badgePlan } from "@steamsets/client-ts/funcs/badgePlan.js";

// Use `SteamSetsCore` for best tree-shaking performance.
// You can create one instance of it to use across an application.
const steamSets = new SteamSetsCore({
  token: "<YOUR_BEARER_TOKEN_HERE>",
});

async function run() {
  const res = await badgePlan(steamSets, {
    targetLevel: 314222,
  });
  if (res.ok) {
    const { value: result } = res;
    console.log(result);
  } else {
    console.log("badgePlan failed:", res.error);
  }
}

run();
```
