# Search

## Overview

Cross-resource search and trending data.

### Available Operations

* [getTrending](#gettrending) - Top search queries in a window, by search count
* [parseQuery](#parsequery) - Read the filters a typed search asks for

## getTrending

Top search queries in a window, by search count

### Example Usage

<!-- UsageSnippet language="typescript" operationID="search.getTrending" method="post" path="/v1/search.getTrending" -->
```typescript
import { SteamSets } from "@steamsets/client-ts";

const steamSets = new SteamSets({
  token: "<YOUR_BEARER_TOKEN_HERE>",
});

async function run() {
  const result = await steamSets.search.getTrending({
    source: "account",
    window: "24h",
  });

  console.log(result);
}

run();
```

## parseQuery

Asks a language model which filters of the page's schema a typed query asks for. The answer is unchecked JSON; the page checks it against its filter definitions.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="search.parseQuery" method="post" path="/v1/search.parseQuery" -->
```typescript
import { SteamSets } from "@steamsets/client-ts";

const steamSets = new SteamSets({
  token: "<YOUR_BEARER_TOKEN_HERE>",
});

async function run() {
  const result = await steamSets.search.parseQuery({
    page: "badges",
    query: "hard to get foil cats",
    schema: "<value>",
  });

  console.log(result);
}

run();
```
