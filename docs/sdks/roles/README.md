# Roles

## Overview

### Available Operations

* [listCustom](#listcustom) - List custom roles

## listCustom

Returns the name, description and icon of every custom role. Built-in roles are not included. Public, no auth required.

const steamSets = new SteamSets({
  token: "<YOUR_BEARER_TOKEN_HERE>",
