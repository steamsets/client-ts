# Market

## Overview

### Available Operations

* [listCurrencies](#listcurrencies) - List Steam currency rates

## listCurrencies

Steam's conversion rate from USD to every wallet currency. Every price the API returns is in USD cents; multiply by perUsd to show it in another currency.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="market.listCurrencies" method="post" path="/v1/market.listCurrencies" -->
```typescript
import { SteamSets } from "@steamsets/client-ts";

const steamSets = new SteamSets({
  token: "<YOUR_BEARER_TOKEN_HERE>",
});

async function run() {
  const result = await steamSets.market.listCurrencies();

  console.log(result);
}

run();
```

### Standalone function

The standalone function version of this method:

```typescript
import { SteamSetsCore } from "@steamsets/client-ts/core.js";
import { marketListCurrencies } from "@steamsets/client-ts/funcs/marketListCurrencies.js";

// Use `SteamSetsCore` for best tree-shaking performance.
// You can create one instance of it to use across an application.
const steamSets = new SteamSetsCore({
  token: "<YOUR_BEARER_TOKEN_HERE>",
});

async function run() {
  const res = await marketListCurrencies(steamSets);
  if (res.ok) {
    const { value: result } = res;
    console.log(result);
  } else {
    console.log("marketListCurrencies failed:", res.error);
  }
}

run();
```
