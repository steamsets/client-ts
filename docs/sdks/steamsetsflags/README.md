# Admin.Flags

## Overview

### Available Operations

* [delete](#delete) - Delete a feature flag
* [deleteOverride](#deleteoverride) - Delete a flag override for an account
* [getAccount](#getaccount) - Get the flags for an account
* [list](#list) - List feature flags
* [setOverride](#setoverride) - Set a flag override for an account
* [update](#update) - Update a feature flag

## delete

Removes the flag's default, role grants and every override in one transaction. A flag the backend checks in code cannot be deleted. Deleting a flag with no rows succeeds. Staff only.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="admin.flags.delete" method="post" path="/v1/admin.flags.delete" -->
```typescript

const steamSets = new SteamSets({
  token: "<YOUR_BEARER_TOKEN_HERE>",
});

async function run() {
  const result = await steamSets.admin.flags.delete({
    flag: "old_flag",
  });

  console.log(result);
}

run();
```

    defaultEnabled: true,
    flag: "bots",
    roles: [
