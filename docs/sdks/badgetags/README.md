# Admin.BadgeTags

## Overview

### Available Operations

* [activity](#activity) - List badge tag activity
* [overview](#overview) - Badge tagging dashboard
* [queue](#queue) - Show the badge tag review queue
* [releaseClaim](#releaseclaim) - Release badge tag claims
* [requeue](#requeue) - Put badges back in the tag review queue
* [taggers](#taggers) - List badge scouts and their work

## activity

Every review, skip, revision, edit, claim release, requeue and AI auto-tag, with the tags each one added and removed and the badge's art, newest first. Tag changes from before the review log show as kind change. Staff only.

## releaseClaim

Clears a scout's claims on pending badges, or only the expired ones, so any scout can claim them again. A scout still working on a released badge gets a not-claimed error on submit. Each badge gets an entry in the badge tag activity log. Staff only.

## requeue

Moves reviewed, skipped or auto-tagged badges back to pending so a scout reviews them again. Their tags stay until that review. Badges already pending or never queued are left alone. Each badge gets an entry in the badge tag activity log. Staff only.
