# Site

## Overview

Site-wide state and live update streams.

### Available Operations

* [announceVersion](#announceversion) - Announce the build a frontend app runs, so its open tabs can offer a refresh. Frontend API key only.

## announceVersion

Announce the build a frontend app runs, so its open tabs can offer a refresh. Frontend API key only.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="site.announceVersion" method="post" path="/v1/site.announceVersion" -->
```typescript
import { SteamSets } from "@steamsets/client-ts";

const steamSets = new SteamSets({
  token: "<YOUR_BEARER_TOKEN_HERE>",
});

async function run() {
  const result = await steamSets.site.announceVersion({
    app: "<value>",
    builtAt: 903755,
  });

  console.log(result);
}

run();
```

### Standalone function

The standalone function version of this method:

```typescript
import { SteamSetsCore } from "@steamsets/client-ts/core.js";
import { siteAnnounceVersion } from "@steamsets/client-ts/funcs/siteAnnounceVersion.js";

// Use `SteamSetsCore` for best tree-shaking performance.
// You can create one instance of it to use across an application.
const steamSets = new SteamSetsCore({
  token: "<YOUR_BEARER_TOKEN_HERE>",
});

async function run() {
  const res = await siteAnnounceVersion(steamSets, {
    app: "<value>",
    builtAt: 903755,
  });
  if (res.ok) {
    const { value: result } = res;
    console.log(result);
  } else {
    console.log("siteAnnounceVersion failed:", res.error);
  }
}

run();
```
